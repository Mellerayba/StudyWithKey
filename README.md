# StudyWithKey

A custom Bluetooth LE macro remote for Quizlet-app navigation — 
built from a breadboard proof-of-concept through to a battery-powered 
custom PCB.

## Status
In progress — Prototype 2 hardware complete (DRC clean and ready to order). 
Firmware for Prototype 2 not yet started.

## Roadmap
- [x] Prototype 1 — breadboard BLE HID proof of concept
- [x] Prototype 2 — custom PCB, USB-C + battery power, hardware complete
- [ ] Prototype 2 — firmware (FSM-based button handling, BLE HID)
- [ ] Prototype 3 — ULP RISC-V coprocessor deep-sleep refactor
- [ ] 3D printed enclosure
